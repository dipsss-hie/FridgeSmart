# FridgeSmart 🥦

FridgeSmart is a Python-based food inventory management project that helps users record food items, track estimated storage dates, and manage their inventory.

## Features

- Add food items with purchase dates and storage locations.
- Estimate storage duration using a built-in ingredient database.
- View remaining days and estimated-date warnings.
- Search for food items by name.
- Remove items from inventory.
- Save inventory data using JSON.
- Validate user inputs and handle common errors.

## Technologies Used

- Python 3
- JSON
- datetime
- pathlib

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python fridgesmart.py
   ```
